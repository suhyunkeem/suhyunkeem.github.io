AI 비서실장

개인 업무용 AI 비서 · Personal AI assistant for one user

무엇인가요

한 사람이 자기 컴퓨터에서 직접 운영하는 개인용 업무 비서입니다. 프로젝트별 업무와 일정을 정리하고, 사용자가 채팅에서 확인한 일정만 사용자 본인의 구글 캘린더에 반영합니다.

이 앱은 일반에 제공되지 않으며, 운영자 본인 계정에서만 사용합니다.

구글 캘린더 사용 범위

이 앱이 직접 만든 캘린더(이름이 [AI]로 시작)와 그 안의 일정만 만들고, 읽고, 바꾸고, 지웁니다. 사용자의 기본 캘린더나 다른 캘린더, 메일, 연락처에는 접근하지 않습니다.

English

A personal assistant run by a single user on their own computer. It only manages calendars it created itself (named [AI] …) in the user's own Google account, and only after the user confirms each change. It is not offered to the public.
