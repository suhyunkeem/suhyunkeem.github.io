1. 누가 쓰나요

AI 비서실장은 운영자 한 사람이 자기 컴퓨터에서 직접 실행하는 개인용 앱입니다. 다른 사람에게 제공하지 않으며, 운영자 본인의 구글 계정만 연결합니다.

2. 구글 사용자 데이터 중 무엇에 접근하나요

  • 권한은 https://www.googleapis.com/auth/calendar.app.created 하나만 요청합니다.
  • 이 앱이 만든 캘린더(이름이 [AI]로 시작)와 그 안의 일정 제목·시간·장소·메모·참석자만 다룹니다.
  • 기본 캘린더, 다른 캘린더, 메일, 연락처, 드라이브 등 그 밖의 데이터에는 접근하지 않습니다.

3. 어디에 쓰나요

  • 프로젝트별 일정을 보여 주고, 사용자가 채팅에서 확인한 일정만 등록·변경·취소합니다.
  • 참석자 초대 메일은 사용자가 화면에서 따로 체크했을 때만 보냅니다.
  • 광고, 판매, 프로필 분석, 제3자 제공에는 쓰지 않습니다.

4. 어디에 저장하나요

  • 로그인 토큰과 일정 사본은 운영자 컴퓨터 안에만 저장하고, 외부 서버로 보내지 않습니다.
  • 일정 내용은 운영자가 업무 정리를 위해 쓰는 AI 비서(Anthropic Claude)에게 전달될 수 있습니다. 이는 운영자 본인이 자기 업무에 쓰는 용도에 한합니다.

5. 보관과 삭제

  • 연결을 끊으면 컴퓨터에 저장된 토큰을 지웁니다. 구글 계정의 서드파티 액세스에서 언제든 권한을 취소할 수 있습니다.
  • 이 앱이 만든 캘린더는 구글 캘린더에서 직접 지울 수 있습니다.

6. Google API Services 사용자 데이터 정책 준수

이 앱이 구글 API로 받은 정보의 사용과 다른 앱으로의 전송은 Google API Services User Data Policy(제한적 사용 요건 포함)를 따릅니다.

English summary

This is a personal app used only by its operator with their own Google account. It requests only the calendar.app.created scope, accesses only calendars it created, stores tokens and calendar copies only on the operator's computer, never sells or shares data, and complies with the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked anytime at Google Account > Third-party access.
